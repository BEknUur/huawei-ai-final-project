# Project 22 — Identifying Who Spoke When in Meetings


Команда: Бекнур, Турарбек, Талант, Азамат, Мерей

## О проекте

**Диаризация** — это ответ на вопрос «кто когда говорил». Система получает запись совещания и размечает её: «0:00–0:15 говорил спикер A, 0:15–0:40 спикер B, 0:38–0:42 одновременно B и C». Распознавать слова или узнавать людей по имени не нужно — только различать голоса и раскладывать их по времени.

**Данные.** Записи реальных совещаний из корпуса [AMI](https://groups.inf.ed.ac.uk/ami/corpus/) (микрофон Mix-Headset) с ручной эталонной разметкой спикеров ([AMI-diarization-setup](https://github.com/BUTSpeechFIT/AMI-diarization-setup), `only_words`). Ответ системы сравнивается с эталоном.

**Исследовательский вопрос.** Насколько растёт ошибка диаризации, когда говорят двое и больше одновременно (overlap), по сравнению с участками с одним говорящим? Из чего состоит ошибка — пропущенные спикеры (missed) или перепутанные (confusion)?

**Сравниваем две системы:**
- **pyannote 3.1** — современный пайплайн, умеет выдавать нескольких спикеров одновременно;
- **VBx** — система из стартовой статьи, на каждый момент выбирает одного спикера.

**Гипотеза:** на перекрытиях VBx теряет сильно (пропускает второго спикера), pyannote — меньше. Проверяем по DER, разложенному на missed / false alarm / confusion отдельно для single и overlap регионов.
